# 验证报告 / Verification

本项目内置无界面冒烟自检模式，可在不干扰用户的情况下验证核心功能。

## 运行方式

```powershell
EduKit.exe --selftest .\selftest.txt
```

退出码 `0` 表示全部通过，非 `0` 表示存在失败项（报告文件中会标出 `FAIL` 行）。

## 覆盖范围

- **数据持久化**：settings JSON 读写与重新加载、数据目录降级；
- **硬件信息**：WMI 硬件信息、磁盘信息、系统激活状态、设备问题；
- **系统管理**：进程枚举、系统服务枚举、启动项读取；
- **网络**：网卡与 IPv4 枚举；
- **显示**：显示模式与分辨率枚举（无图形会话的 CI 环境自动 SKIP）；
- **音频**：Core Audio 音量读取（无音频设备时 SKIP）；
- **清理**：临时文件统计；
- **图吧工具箱**：本机目录检测 + 工具扫描（未安装时 SKIP，属正常情况）。

## 界面验证

11 个页面 × 亮/暗两套主题的界面截图由 `--render` 离屏渲染生成（见 `docs/shots/`），用于检查布局、图标、主题切换是否正常。

## 触控验证

`PanningMode.VerticalFirst` 惯性平移与自研 `SmoothScrollViewer` 缓动滚动已编译进程序；由于当前构建环境无触屏设备，触控手感需要在真实触屏 / 触控板设备上确认。

## 未自动化验证（需要人工环境）

- 真实投影仪 / 第二显示器的显示模式切换；
- 打印机、麦克风等外设；
- 物理关机 / 重启 / 睡眠（自检不会触发，避免误关机）；
- 以管理员身份执行 SFC / DISM / 网络重置 / 服务启停（需要人工确认 UAC）。
