# 验证报告 / Verification

本项目内置无界面冒烟自检模式，可在不干扰用户的情况下验证核心功能。

## 运行方式

```powershell
EduKit.exe --selftest .\selftest.txt
```

退出码 `0` 表示全部通过，非 `0` 表示存在失败项（报告中会标出 `FAIL` 行）。

## 覆盖范围

- **数据持久化**：settings JSON 读写与重新加载、数据目录降级；
- **硬件信息**：WMI 硬件信息、磁盘信息、系统激活状态、设备问题、SMART（管理员时）；
- **系统管理**：进程枚举、系统服务枚举、启动项读取；
- **性能监控**：Windows 性能计数器可用性；
- **网络**：网卡与 IPv4 枚举；
- **显示**：显示模式与分辨率枚举（无图形会话的 CI 环境自动 SKIP）；
- **音频**：Core Audio 音量读取（无音频设备时 SKIP）；
- **清理**：临时文件统计；
- **应用更新**：GitHub Releases 最新版本查询（仓库已迁移至 MEIMAOA/SysKit）；
- **图吧工具箱**：本机目录检测 + 工具扫描；在线版本与体积查询。

## 未自动化验证（需要人工环境）

- SMART 硬盘健康（需管理员权限，本次以普通权限运行故 SKIP）；
- 磁盘分析的实际扫描（需要选择真实目录运行，截图页为空态）；
- 图吧工具箱完整下载安装（约 300 MB+，本次仅验证在线版本查询）；
- EduKit 自动更新实际替换重启（需要发布比当前更新的版本）；
- 局域网扫描 / 路由跟踪 / 编辑 hosts / 创建还原点（需要真实网络与管理员权限）；
- 触控手感（无触屏设备）；物理关机 / 重启 / 睡眠（自检刻意不触发）。
