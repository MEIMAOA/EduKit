# 验证报告 / Verification

本项目内置了无界面冒烟自检模式，可在不干扰用户的情况下验证核心功能。

## 运行方式

```powershell
EduKit.exe --selftest .\selftest.txt
```

退出码 `0` 表示全部通过，非 `0` 表示存在失败项（报告文件中会标明 `FAIL` 行）。

## 覆盖范围

- **数据持久化**：settings / roster / timetable / launcher 的 JSON 读写与重新加载；
- **业务逻辑**：名单解析、值日分组、课程表单元格读写；
- **系统接口**：网卡与 IPv4、显示模式与分辨率枚举、Core Audio 音量、WMI 硬件信息；
- **局域网快传**：真实启动 HTTP 服务，完成首页、文件列表 API、上传、下载（内容比对）、删除的端到端测试；
- **数据目录降级**：当 `%APPDATA%` 不可写时自动回退到可写位置并验证。

## 界面验证

13 个页面 × 亮/暗两套主题的界面截图由 `--render` 离屏渲染生成（见 `docs/shots/`），用于检查布局、图标、主题切换是否正常。

## 未自动化验证（需要人工教室环境）

- 真实投影仪 / 第二显示器的显示模式切换；
- 打印机、麦克风等外设；
- 物理关机 / 重启 / 睡眠（自检不会触发，避免误关机）。
