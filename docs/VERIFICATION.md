# 验证报告 / Verification

本项目内置无界面冒烟自检模式，可在不干扰用户的情况下验证核心功能。

## 运行方式

```powershell
EduKit.exe --selftest .\selftest.txt
```

退出码 `0` 表示全部通过，非 `0` 表示存在失败项（报告中会标出 `FAIL` 行）。

## 覆盖范围

- **数据持久化**：settings JSON 读写与重新加载、数据目录降级；
- **硬件信息**：WMI 硬件信息、磁盘信息、系统激活状态、设备问题；
- **系统管理**：进程枚举、系统服务枚举、启动项读取；
- **性能监控**：Windows 性能计数器可用性（CPU 计数器读取）；
- **网络**：网卡与 IPv4 枚举；
- **显示**：显示模式与分辨率枚举（无图形会话的 CI 环境自动 SKIP）；
- **音频**：Core Audio 音量读取（无音频设备时 SKIP）；
- **清理**：临时文件统计；
- **应用更新**：GitHub Releases 最新版本查询（网络不可用时 SKIP）；
- **图吧工具箱**：本机目录检测 + 工具扫描；在线最新版本、安装包 / 便携版体积查询。

## 界面验证

12 个页面 × 亮/暗两套主题的界面截图由 `--render` 离屏渲染生成（见 `docs/shots/`），用于检查布局、图标、主题切换是否正常。

## 触控验证

`PanningMode.VerticalFirst` 惯性平移与自研 `SmoothScrollViewer` 缓动滚动已编译进程序；由于当前构建环境无触屏设备，触控手感需要在真实触屏 / 触控板设备上确认。

## 未自动化验证（需要人工环境）

- **图吧工具箱完整下载安装**（安装版约 303 MB、便携版约 407 MB，本次仅验证在线版本与体积查询）；
- **EduKit 自动更新实际替换重启**（需要发布比当前更新的版本才能端到端验证）；
- **局域网扫描 / 路由跟踪 / 编辑 hosts**（需要真实局域网与管理员权限）；
- 真实投影仪 / 第二显示器的显示模式切换；
- 以管理员身份执行 SFC / DISM / 网络重置 / 服务启停、创建还原点；
- 物理关机 / 重启 / 睡眠（自检不会触发，避免误关机）。
